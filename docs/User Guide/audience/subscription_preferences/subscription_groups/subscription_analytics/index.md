# Subscription Analytics

> Use the **Subscription Analytics** tab to review how a subscription group’s membership changes over time, including opt-ins, opt-outs, user deletions, and which campaigns or Canvases drove those changes.

View subscription group analytics by going to **Audience** > **Subscription Group Management** > **Subscription Analytics**. 

Then, use filters to adjust the scope of your report:

| Filter | Description |
| --- | --- |
| Date range | Limits the report to the selected dates. The page defaults to the last 31 days ending yesterday. You can select up to 365 days of history. |
| Channel | Limits the **Subscription Group** list to groups for that channel. Choose **All Channels**, **Email**, **SMS**, **WhatsApp**, **LINE**, or **KakaoTalk**. |
| Subscription Group | Selects the group to report on. Archived groups aren’t listed. If you change the channel, Braze resets the selected group to the first available group for that channel. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Subscription Analytics filters"}

## Summary tiles

The summary tiles show current and period totals for the selected subscription group:

| Tile | Description |
| --- | --- |
| Subscription Group Size | Total number of users currently subscribed to the group. |
| Total Opt-ins | Users who opted in during the selected date range. |
| Total Opt-outs | Users who opted out during the selected date range. |
{: .reset-td-br-1 .reset-td-br-2 aria-label="Subscription Analytics summary tiles"}

## Subscriber Growth over time

The **Subscriber Growth over time** chart shows daily membership changes for the selected group and date range. The chart includes:

- Daily subscription size
- Opt-ins
- Opt-outs
- User deletions

A table under the charts lists the same daily metrics in columns for **Date**, **Total Size**, **Opt-ins**, **Opt-outs**, and **User deletions**.

## Opt-ins and opt-outs by campaign or Canvas

The **Opt-ins by Campaign or Canvas** and **Opt-outs by Campaign or Canvas** attribution charts show which campaigns and Canvases contributed the most subscription changes in the selected range.
