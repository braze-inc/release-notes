## Databricks OpenSharing

Databricks OpenSharing is part of Braze Data Distribution. Use it to query Braze engagement and campaign data directly in your Databricks account.

For setup and implementation details, see [Databricks OpenSharing](https://www.braze.com/docs/opensharing/). For additional Data Distribution options, see [Braze Currents](https://www.braze.com/docs/user_guide/data/distribution/braze_currents) and [Exporting Braze Data](https://www.braze.com/docs/user_guide/data/distribution/export_braze_data).

## Snowflake Data Sharing

Snowflake Data Sharing is part of Braze Data Distribution. Use it to query Braze engagement and campaign data directly in your Snowflake instance.

For setup and implementation details, see [Snowflake Data Sharing](https://www.braze.com/docs/partners/data_and_analytics/data_warehouses/snowflake/data_sharing). For additional Data Distribution options, see [Braze Currents](https://www.braze.com/docs/user_guide/data/distribution/braze_currents) and [Exporting Braze Data](https://www.braze.com/docs/user_guide/data/distribution/export_braze_data).
