# Voucherify

> [Voucherify](https://www.voucherify.io/) is an incentive optimization engine that enables you to manage promotions, coupons, loyalty programs, referrals, and personalized incentives. With Braze, you can deliver dynamic incentives within campaigns and Canvases, trigger incentive actions, and synchronize promotion data between systems—without building custom backend systems.

## Prerequisites

To use Voucherify with Braze, you will need:

- A Voucherify account  
- A Braze account  
- Voucherify API credentials  
- Access to Braze Connected Content, custom attributes, or both  

## Integration overview

You can integrate Voucherify with Braze to:

- Fetch incentives in real time using Connected Content  
- Trigger incentive actions from Braze  
- Send events to Braze for segmentation  
- Store incentive data in Braze user profiles  
- Send custom attributes to Braze with personal voucher codes
